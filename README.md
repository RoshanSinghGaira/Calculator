🚀 HOW TO ACCESS THE APPLICATION

⚠️ IMPORTANT: The application is provided as a ZIP file.
Download and extract the ZIP before running the calculator.

⚠️ DO NOT TRY TO OPEN THE EXE DIRECTLY FROM GITHUB
GitHub does not run Windows .exe applications directly.

1️⃣ DOWNLOAD THE ZIP

Download the Calculator ZIP file from this repository.

For example:

Calculator.zip


2️⃣ EXTRACT THE ZIP

After downloading:

Right-click the ZIP → Extract All → Extract

Open the extracted folder.

Do not run the .exe directly from inside the ZIP.


3️⃣ RUN THE CALCULATOR

Inside the extracted folder, find the Calculator application .exe file.

For example:

Calculator.exe

Double-click the .exe file to launch the application.


4️⃣ ⚠️ WINDOWS SECURITY WARNING

Windows may display:

"Windows protected your PC"

when you open the application.

If this appears:

Click More info → then click Run anyway

The calculator will then open normally.


🎯 PROJECT

This project demonstrates a functional calculator application developed using C++ and Qt Widgets.

The graphical user interface is created programmatically using C++ code, providing a clean and modern calculator interface.

The application supports basic arithmetic operations along with additional features such as decimal numbers, backspace, positive/negative conversion, and error handling.
